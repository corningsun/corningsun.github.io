Mac 常用设置

发表于 2018-07-17 更新于 2023-06-19

fn 设置

勾选 ‘将 F1、F2 等键用作标准功能键’，否则 IDE 中各种快捷键都要加上 fn

MacOs Ventura 版本 可以直接搜索 ‘功能键’ 查找

触摸板设置

勾选 ‘轻点来点按’，可以省下不少力气

触发角设置待机

系统偏好配置 -> 桌面与屏幕保护程序 -> 触发角

显示文件扩展名

访达 > 设置 > 高级 > 显示所有文件扩展名
